# 上岸鸭飞书功能增量优化记录（2026-10-23）

## 本轮修改

1. `public_link_reader.py`
   - 飞书公开链接优先尝试匿名读取页面正文。
   - 手动跟随有限次数的跳转；每次跳转重新校验目标地址，避免把登录页当正文。
   - 若跳转到飞书登录页、且未配置应用凭证，返回明确的 `FEISHU_AUTH_REQUIRED` 提示，而不是只报模糊的跳转错误。

   - 已读取资料可以手动调整类别；对于带目录子页信息的飞书 Wiki，新增子页分类预览。
   - 分类仅保存为网页内的个人整理标记，并写入导出的核对包；不会移动、删除或覆盖飞书原文件。
   - 版本标识更新为 `1.2-feishu-categories`。

3. `index.html`
   - 更新 `source-workflow.js` 的缓存版本号，避免浏览器继续使用旧脚本。
