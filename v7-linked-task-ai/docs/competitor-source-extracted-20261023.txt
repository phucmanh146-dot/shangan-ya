循环机制
价驭商弈“分析—建议—执行”闭环；平台工作流有循环节点；常见的循环是模型反复调工具，直到答出来
有界循环、重复调用拦截；每次帮助后按实际尝试决定继续、换策略、求助或停止
两层循环。内循环看人有没有动手：帮一次，看他做没做那个5分钟动作，没做就换讲法或拆小，最多两轮就停下问原因。外循环看作品有没有变好：V1到行动卡到V2，按原标准复核，只重排剩余。停止条件绑在“人做了没、作品过了没”，不是“模型说完了没”
讲解后不是点“懂了”，而是交一个小产物；复核页逐条显示通过、未通过、未知
上下文管理
知识库检索（千帆有切片管理和命中测试）；医链智擎整合PubMed、社保平台；常见做法是把相关文档塞进去
来源正文有预算；优先装入当前材料、原判据和近期失败；摘要附原记录引用
按“这一步”装配，不按“这个话题”：当前文件那一段、这一步的验收标准、最近两次失败、他刚选的状态、他对哪种帮助有反应。同一个问题，累的时候和精神好的时候得到的帮助不一样，也不会重复用失败过的讲法
同一段材料，选“看不懂”和选“有点累”得到两种不同处理，并说明为什么
工具调用
城市交通接实时路况；赛博小导用多Agent自动生成检索式；平台提供插件和MCP
检索、读取、版本存储、诊断、规划、复核；记录工具输入、结果、错误和证据；失败不能记成功
多两类别人少有的工具。一类作用在人身上：休息计时、接续卡、求助卡生成、站外提醒。一类作用在证据上：术语翻译后再检索、找不到就拒答、每条结论回到原文位置
搜一个查不到的问题：系统先翻译术语，再说找不到，当场生成一张能发给老师的求助卡
跨对话记忆
主流记忆记“你是谁、到哪了”：等级、进度、错题；全民会急救按学习档案推送方案
能匹配已有项目并确认后接续；保存现场和承诺；偏好可查看修改，避免串项目
记“没做完的事”：答应了谁、什么时候交、什么条件下回来；再记“哪种帮助对这个人有用”。回来先确认是不是同一个项目，再接到准确的微动作；材料变了先提示，不接到过期位置
隔天新开对话说“继续昨天那个”，系统先确认项目，再给出昨天停下的那一步和5分钟动作
最能拉开差距的三点：
存档点： 存位置和下一步，不只存等级和进度。
双循环： 停止条件绑在人动没动手、作品过没过，不绑在模型说没说完。
记住什么帮助对你有用： 笑话、类比还是休息，用得越多选得越准。
这些做法在PRD里大多已经有设计，缺的是一条真人跑通的演示。答辩时用表里“演示”一列的5个镜头，比讲架构图更有说服力。

冷启动：不知道第一步、查不到资料怎么办
能力不足的人卡在起点，多半不是懒，而是三道坎：不知道“做完”长什么样，不知道该搜什么词，第一步太大。系统按下面顺序拆掉这三道坎，目标是第一次打开5分钟内做出一个看得见的V0。
先给样子，再给任务。 从A已抓的往届获奖作品里挑一两个最接近的，拆成“它由哪几块组成”，再给半填空模板。认知负荷研究里的样例效应说的就是这个：新手看着做好的样例学得更多，熟练后再撤掉提示、改为自己做。来源
3分钟试做，测出真实水平。 不问“你会不会做智能体”，而是请他在平台上新建一个智能体、发一句话，或写一句“我的用户是谁、痛点是什么”。做出来记通过，卡住记卡在哪；自述只作参考。
第一步不超过5分钟，而且必须产出东西。 例如“复制模板，只填‘用户是谁’这一格”。有了V0，诊断、行动卡、V2这套闭环才转得起来。
把“如果…就…”写进行动卡。 例如“如果今晙9点打开电脑，就先填第2格”。这种事先写好的条件计划，在一项汇总94项检验的元分析里，对达成目标有中到大的效果（d=0.65）。来源
找资料由系统代劳，只给当前这一步要的。
先把大白话翻成搜得到东西的术语，比如“想让智能体记住上次聊的”→“长期记忆、RAG、向量数据库”。这一步解决“不知道行话就搜不到”。
优先在知识库里找：赛事通知、往届作品、教程。最多给1到3条，每条写明看哪一段或视频第几分钟、为什么适用。
找不到就直说，不硬编，然后给两条出路：一张写好背景的求助卡，发给老师、学长或队友；或一条替代路径，先用模板或模拟数据把这一步跑通。
每次找不到都记下来，补进知识库和评测集，下一个人就找得到。

这些技术背后的原理
这几类技术都有成熟论文和平台积木，光说“用了RAG、用了多智能体”很难拉开分差；分差出在每类技术的短板补没补上。

检索增强（RAG）
先从资料库检索相关片段，再让模型据此生成，把模型自带的“参数记忆”和外挂的“非参数记忆”合起来用（Lewis等，2020）
检索到了不等于用对了，模型仍可能写出资料里没有的话
每条诊断必须带原文位置和引文；复核时拒收不存在的引文
多角色、多智能体
把规范流程写进提示词序列，按装配线分给不同角色接力（MetaGPT，2023）
角色越多越难查错，中间结果靠模型互评
只设A诊断、B规划两个角色，交接字段固定；缺来源、负责人、产物或验收条件的不进下一步
工作流和智能体
工作流按预先写好的路径调用模型和工具；智能体由模型自己决定下一步，靠每一步从环境拿到的真实结果判断进展，并设最大轮数等停止条件（Anthropic，2024）
工作流跑完就停；智能体容易空转
外循环的环境反馈是真人交来的新版作品；内循环有轮数上限和重复调用拦截
工具调用
推理和行动交替：先想，再调检索等外部接口，按返回结果再想（ReAct，2022）
工具返回错了，模型照样往下编
每次调用记录输入、结果和错误，失败不能记成功
记忆
借鉴操作系统的分层内存，在有限窗口里把记忆调入调出（MemGPT，2023）；扣子、千帆用变量和数据库记用户信息
学习助手记的是“这人是谁、什么水平”，不是“事做到哪”
记忆存存档点：任务、位置、卡点、下一步、返回条件
长上下文
关键信息放在输入中间时，模型表现明显下降（Liu等，2023）
整份材料塞进去，判据被埋在中间
优先装当前材料、原判据和近期失败；超6万字拒收并拆分
反思和核查
模型根据任务反馈写反思、存进记忆再试（Reflexion，2023）；先出草稿，再列核查问题逐个独立回答（CoVe，2023）
反馈来自模型自己，容易自我认可
复核以真人新版作品和原判据为准，模型自评不算验收
上岸鸭的大模型流水线
上岸鸭设计里调用大模型的有五处，每处都规定了输入、必须交出的字段和放行条件；这套校验门是它和获奖作品在技术上最实在的差别。

大模型流水线对比 · 获奖作品4步到头，上岸鸭7步一个循环
上面一行是典型获奖作品：一次输入、一次生成，到方案就停。下面是上岸鸭：②③⑥三处校验门挡住没有出处、没有产物、版本不对的输出；⑥没过就回到③，只针对剩余问题再出卡。

PR #22已经做了证据门、具体微动作门槛、有界循环和上下文预算，相关70项测试通过；但测试用的是受控模型回复，不代表真实模型的效果。整条链能反查：项目 → 判据 → 作品版本和位置 → 诊断版本和差距 → 计划和微动作 → 提交 → 复核 → 人工确认 → 剩余问题。
能写进PPT的两个创新点
首届提交说明要求创新页“突出1-2个创新点”，所以只报这两条；科普视频、笑话、多角色分工别人也能做，放进支撑页。
创新点一：人做、模型验的成果闭环。 别的智能体是模型干活、模型说干完了；上岸鸭是人改作品，模型拿原判据逐条验新版，没过就只针对剩余问题再出行动卡。
原理：Anthropic把“每一步从环境拿到真实结果”列为智能体的关键；上岸鸭的环境反馈就是真人交来的新版作品。这属于“评估-优化”模式，只是优化者换成了人。
和获奖作品比：上面16个作品的输出停在方案、报告或建议，最多由机器去执行（价驭商弈）；没有一个拿用户改完的作品回头验。
怎么证明：同一批真实材料，比较通用聊天、单个智能体和上岸鸭三种做法，报V1到V2多通过几条判据、误放行几次、返工几次。
演示画面：上传V1，点开诊断卡上的原文位置；改一处交V2；复核表逐条变绿，剩下一条自动生成新卡。
创新点二：停在哪、接回哪的中断接续。 用户点“听不进去”或“真的累了”时，系统先存档，再分流：前者把当前论文换成通俗讲法，回原段落做一个小动作；后者休息后接续原任务，或只重排剩余。
原理：每次调用模型的上下文由当前材料、原判据、近期失败和存档点拼成，不靠翻聊天记录；这是“路由”加分层记忆，记的是事做到哪。
和同类比：扣子、千帆上的学习助手用变量记等级和进度；我们查到的公开资料里，没有作品按中断原因分流、再接回原来那一步。
怎么证明：重要任务返回率、从中断到重新动手的分钟数、讲解后能否复述并做出原动作。
演示画面：读论文时点“听不进去”，出类比和原文对照，一键回到原段落填对比表一格；点“真的累了”，5分钟后回到同一步。
跨学科视角（第二页）。 教育心理学给出“为什么这样设计”：样例效应支持行动卡先给示范再逐步撤掉；执行意图研究（94项独立检验，效应量d=0.65）支持把“何时、何地、做哪一步”写清；微休息能提神、减疲劳，但不保证提高成绩，所以休息只承诺接得回来。大模型工程给出“怎么做到”：可验证输出和以结果判停的闭环。政策上，创新点一对应《“人工智能+教育”行动计划》的“学生学习全过程纵向评价”，创新点二对应“动态优化学习路径”。
