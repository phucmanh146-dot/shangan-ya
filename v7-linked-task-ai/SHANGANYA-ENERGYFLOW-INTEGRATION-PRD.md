## 1. 产品初衷

上岸鸭不是普通待办清单，不是独立的精力检测页，也不是把工具集合在一起的 AI 门户。它是私人执行工作台：面对多条任务主线、时间估计容易理想化、遇到困难会消耗额外精力的现实，帮助用户在有限时间和当前精力下完成最重要的产出。

核心原则：**任务是主线，资料是证据，AI 负责解卡，精力决定节奏，用户确认保护原始数据。**

成功标准不是按钮更多，而是用户从现有任务开始，能知道下一步做什么；遇到卡点时快速获得资料和 AI 帮助；疲惫时可以减负或休息；实际耗时与复盘能改善未来计划。

## 2. 不可破坏的产品约束

1. 保留原工作台导航、每日清单、任务工作区、四象限、截止日期、优先级、完成状态、习惯、历史和个人资料。
2. 任务只维护一份。精力模块读取原任务 ID 和状态，不建立平行任务池。
3. 真实计时只维护一份。专注时长沿用原番茄钟/ `durationLog`；不新建第二套计时器或虚构历史。
4. 精力排期只维护一个事实来源。复用原 `energyHistory`、`plannerSettings`、`wellbeingPlan` 与原精力排期逻辑，不另建冲突的精力分数。
5. AI 给出的新任务、时间变更或优先级变更必须先预览、用户确认后再写回；不得静默覆盖原数据。
6. 原型或入口不等于真实能力。微信、飞书、Obsidian、模型、视频等状态必须基于真实接口与实际结果展示。
7. 摄像头默认关闭；本轮只提供可选本地预览，不推断心理状态、不上传画面。
8. 不把一天排满。保护固定事项、休息、放空/娱乐时间与突发任务缓冲。

## 3. 市场交互参考与取舍

参考成熟产品公开的交互模式，而不是照搬所有功能：

- **TickTick** 将任务、日历/时间线、专注计时、习惯和统计放在同一产品里，并支持从任务关联专注记录。借鉴：任务与执行时间关联、一个地方查看日程和进度；不照搬其通用规则，精力建议必须以用户实际记录校准。参考：[TickTick 功能页](https://ticktick.com/features)、[专注计时帮助](https://help.ticktick.com/articles/7055782010496745472)。
- **Todoist** 使用优先级和过滤视图帮助用户快速聚焦当下重要事项。借鉴：默认视图只显示当前相关任务，复杂条件按需筛选；不新增重复的任务分类系统。参考：[Todoist 优先级](https://www.todoist.com/help/articles/set-a-priority-in-todoist-Wy82Jp)、[筛选器](https://www.todoist.com/help/todoist/features/introduction-of-filters-V98wIH)。

由此采用四项交互规则：默认收起非当前任务工具；每次只打开一个子模块；常用动作一到两步完成；所有自动建议说明依据并允许用户确认/撤销。

## 4. 去重与整合决策

| 能力 | 唯一事实来源 | 新交互位置 | 去重规则 |
|---|---|---|---|
| 任务、DDL、优先级、状态 | 原每日清单/任务 ID | 原任务入口 | 不另建 EnergyFlow 任务池 |
| 精力、固定事项、休息、重排 | 原 EnergyFlow / 左侧排期引擎 | 执行中枢「精力与排期」 | 不维护第二套精力分数或重排算法 |
| 专注计时、实际耗时 | 原番茄钟及 `durationLog` | 原番茄钟入口；中枢提供快捷跳转 | 不再做第二个计时器 |
| 精力历史 | 原 `energyHistory` 与排期设置 | 「个人规律」只读汇总 | 新增记录不得冒充旧历史 |
| 疲惫/卡壳事件 | 原精力排期事件；仅缺失的复盘事件存入 `energyFlow` | 「专注与疲惫」 | 同一事件不在多处重复保存 |
| 个人执行教练 Demo | 原 Demo 页面与交互 | 中枢按需加载 | 不新增独立侧栏入口；不删除 Demo 自身独有交互 |
| 模型/API 设置 | 唯一模型配置页与后端会话 | 中枢按需加载 | 不再增加重复“连接 AI”入口；配置成功必须由真实请求证明 |
| 晚间复盘 | 新增 `energyFlow.reviews` | 「晚间复盘」 | 仅保存原系统没有的复盘字段，不改原任务状态 |
| 摄像头 | 浏览器本地媒体权限 | 「专注与疲惫」可选预览 | 默认关闭，停止时释放轨道；不保存或上传画面 |

## 5. 推荐信息架构

在原每日清单中增加一个默认收起的「精力与执行中枢」，而不是添加新的主导航。

- **精力与排期**：承载原有精力排期模块。确认当前状态后，查看任务容量、休息/缓冲和原排期建议；只有用户确认才应用排期。
- **专注与疲惫**：快速记录“有点慢 / 读不进去 / 需要休息”，直接跳到原番茄钟或任务工作区；可选择开启本地摄像头预览。
- **个人规律**：只读展示真实精力历史、真实番茄钟记录数量与有足够样本时的耗时统计。样本不足明确显示，不编造规律。
- **晚间复盘**：三问式记录耗时偏差、疲惫时段、有效恢复方式；支持查看、导出与清除新增复盘数据。
- **个人执行教练**：按需加载既有 Demo，保留其自身功能，不默认展开。
- **AI 配置**：按需加载既有模型配置页；嵌入模式不重复显示“返回工作台/打开 AI 工作区”导航。

## 6. 动态排期原则

```
可投入时间 = 今日可用时间 - 固定事项 - 保护休息/娱乐 - 任务间缓冲
建议任务时长 = 个人同类实际耗时参考 + 查资料时间 + 难度/精力调整 + 卡壳缓冲
```

- 优先保护有硬截止时间且重要的任务；精力偏低时降低工作段长度、拆分任务或切换轻任务。
- 连续卡壳时先保存断点，提示最小下一步、求助或短暂离屏，不继续无限计时。
- 休息、发呆、刷视频和看电视剧可以被用户主动保留为计划时间，不把它们自动认定为失败。
- 预估是建议，不是客观测量。没有个人历史时标记“初始估计”；样本不足时不推断固定疲惫时段。
- 重新排期先预览；应用前显示受影响任务与原因；用户确认后才写回。
