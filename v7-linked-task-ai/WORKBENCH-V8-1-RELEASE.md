# 上岸鸭工作台：连接 AI 功能整合说明（2026-10-24）

## 本轮修改方向
按用户纠正后的要求：与 Agent 项目无关。将录屏展示的 AI 交互和指定飞书资料入口整合到原工作台的“连接 AI”功能，不另加独立审计面板，不重做任务系统。

## 已落入“连接 AI”功能的内容
- AI 模型供应商下拉列表：从当前服务端 /api/ai-providers 动态读取；选择供应商后展示官方 API 文档链接。
- 配置 / 测试 API：API Base URL、模型 ID、密钥、真实模型列表读取、实际请求测试。
- 移除 AI 启动时静默回退到 CC Switch 配置的行为，并关闭旧的本机 `/api/cc-switch` 与 `/api/cc-switch/connect` 路由；不会在用户未确认时切换模型来源。
- 对话中关联已有任务或目标（可选），不自动新建/改动任务和截止日期。
- 文字提问、上传/拖入 Word、PDF、表格、图片、音频、视频、字幕等文件。
- 视频解析、可选语音转写、联网搜索、深入分析。
- 网页链接读取、微信原始数据 AI（按用户主动选择的数据）、回答转思维导图和讲解视频（实际可用性取决于服务端和已配置模型）。
- 飞书文档快捷入口：已在同一 AI 输入区的操作栏加入“飞书文档”按钮；默认填入用户指定的 Wiki 地址，尝试通过本机已登录飞书读取正文，并作为当前 AI 对话附件。也保留飞书官方 API 凭证和测试设置。

## 保护原则
- 不删除或覆盖原任务、截止日期、重要/紧急清单和历史数据。
- 不把飞书/Obsidian/微信标记为“已连接”，除非真实读取/接口验证成功。
- 不读取浏览器密码或 Cookie；不自动发送微信消息。
- Obsidian 本机 Vault 仍需要本机桥接服务，公网网页不能直接访问用户电脑文件。
