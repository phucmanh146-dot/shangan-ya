# 上岸鸭 V8 增量：微信聊天记录继续采集

本增量基于 `feature/linked-task-ai-v7`，不重做工作台、不修改既有任务、截止日期或账号数据。

## 这次改动
- 修复微信资料中心“继续读取更多”按钮一直禁用且没有点击事件的问题。
- 点击后，桌面端读取器将鼠标移到当前微信会话消息区域，向上滚动，再对可见窗口执行 OCR。
- 每批消息追加到当前批次，并按群名、文字和 OCR 发送者标记去重；旧批次在读取失败时保留。
- 状态栏明确显示本次识别数、去重后新增数和累计数。
- OCR 结果仍需用户核对；只采集可见界面，不声称导出了完整历史。不会发送微信消息、删除聊天或修改会话。

## 验收步骤
1. 在真实 Windows 设备启动本机读取桥接并打开微信。
2. 选择目标群，核对搜索结果后点击“读取当前可见画面”。
3. 点击“继续读取更多”，确认微信会话向上滚动、预览更新、消息累计且重复片段被过滤。
4. 让目标窗口失焦或关闭桥接，确认页面显示失败而不是伪造成功，并保留先前批次。
5. 勾选消息后再交给 AI；未勾选内容不应被发送。
6. 在目标设备执行 `node --check p2-wechat-ai.js` 与 `python -m py_compile sy_wechat_reader.py`，再进行实际 UI 验收。

## 限制
- 这项滚动 OCR 是可见屏幕采集，不等于微信全部历史记录的数据库导出。
- 实际运行依赖 Windows 微信窗口、OCR 依赖、正确的本机桥接路由和权限。当前会话的 Remote Desktop Commander 设备离线，因此尚未完成本机联调。
- 这条分支没有自动部署到 Railway。公网网页不能直接读取用户电脑中的微信数据；公网与本机之间必须通过明确授权且经过验证的桥接服务。
