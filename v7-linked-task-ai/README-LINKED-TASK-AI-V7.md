# 上岸鸭工作台 V7 — 关联任务 AI 增量版

## 版本目标
基于原有 shanganya-full-public-20261017 工作台副本进行增量优化。没有重做任务系统，没有覆盖原目录，也没有自动修改原任务数据。

## 本版改动
- 主工作台导航把 P2 入口标识为「关联任务 AI」，并为嵌入式页面增加版本查询参数，避免继续命中旧缓存。
- AI 深度问答页增加「关联原有任务」选择器，直接读取同源浏览器 localStorage 中当前登录账号的 shangan_ya_app_data_v1 任务。
- 关联时携带原任务 ID、名称、类别、状态、原截止日期、步骤、备注及资料链接；不会更改原任务。
- 把任务上下文中的 HTTP(S) 资料链接加入本轮来源读取请求，飞书 Wiki 等链接由原有后端尝试读取，并保留每条来源的真实状态。
- 如果页面运行在本机 localhost/127.0.0.1 服务上，会尝试通过原有 /api/vault、/api/vault-search、/api/vault-read 读取本机 Obsidian 笔记；公网页面不能直接访问本机知识库时，会明确报告未读取，而不是伪报成功。
- 增加「从最新 AI 回答提取待办」：只从明确的编号/项目符号行动项提取；可编辑名称、类别、截止日期和时间；确认后才写入原任务数据；重复项默认取消勾选并在保存时再次去重。
- 新任务记录来源及关联原任务 ID，不覆盖已有任务，不猜测未明确的截止日期。
- 原有图片、文档、视频上传及 AI 回答流程继续使用原来的后端接口。

## 必要限制
- 本次只生成了新的本机项目副本；没有把改动部署到 Railway，也没有修改生产网站。
- 飞书私有 Wiki 是否能读取取决于后端实际配置的应用凭证与文档权限。若 FEISHU_APP_ID / FEISHU_APP_SECRET 未配置，必须显示真实失败状态。
- 本机 Obsidian 读取只在有本机服务、且该服务实际连接了 Vault 时可用。公网部署不能仅凭浏览器页面读取用户电脑上的文件。
- 新增待办只有用户确认后才写入本机浏览器任务数据；若工作台没有即时刷新，请刷新任务列表。


## V8 增量：回答可视化与 HeyGen 数字人视频
- 每条 AI 回答新增「生成思维导图」：从 Markdown 标题、列表和正文整理出可复制的大纲；导图由浏览器渲染，建议对照原文核验。
- 保留原有「生成结果讲解视频」：生成带动态字幕分镜的 WebM，无声版本会明确标注。
- 新增可选「HeyGen 数字人视频」：用户自行提供 HeyGen API Key，服务端按会话内存保存，真实读取数字人与声音列表，提交生成任务并查询状态；生成前需用户确认，可能产生费用。Key 不写入浏览器 localStorage、聊天记录或仓库。
- HeyGen API 未配置时，原有 AI 对话、思维导图和无声 WebM 仍可使用。公网部署不能直接读取本机 Obsidian 文件。


## 微信资料采集与任务编排（2026-10-25）
- 本机模式使用同源 `127.0.0.1:8877`，移除失效的 `8901` 转发；公网页面会明确提示本机微信不能由云端直接读取。
- 微信历史目录初始化增加状态轮询；历史消息可批量勾选交给原有 AI 卡点助手分析，生成候选任务前保留原文、群名、时间和链接。
- 新任务仍需用户确认；不自动发送微信消息、不改写微信历史、不自动覆盖原任务。
- 历史读取依赖本机现有授权组件；无权限、依赖缺失或数据不完整时显示失败原因，不伪造连接成功。


## 微信本机桥接修复（2026-10-25）
- 公网工作台不能直接读取桌面微信；用户点击微信功能时，前端只尝试连接本机 127.0.0.1:8877 的桥接。
- 本机桥接仅允许两个明确的上岸鸭 Railway 来源，配对令牌只存在于本机服务进程内存，服务重启后失效；真实微信接口请求需要令牌。
- 未启动本机服务、浏览器未允许本机网络、微信未登录或权限/依赖不足时，界面应显示实际失败原因，不报告假连接。
- 原有任务、四象限、资料解析、Obsidian/飞书入口和精力排期逻辑保留；微信候选任务需用户确认后再写入原任务。
