# 模拟输入：核对数据分析

CSV是人为构造的开发材料，不是用户问卷、蒙牛项目数据或真实回收业务记录。

领到的任务：“把数据分析做好，完善方案”。当前草稿写“回收率100%，所有记录均有效”。目标：按唯一record_id核对重复；数量含义按列名与本例设定；记录缺失分母、零分母和排除理由，再计算有效记录的合计returned_bottles/合计collected_bottles。

重复的R03两行内容完全相同，本例允许保留一行并记录去重。R05缺collected_bottles，不能补猜数值或当作0；R04为0/0，不计算单日比例。若真实输入出现同ID不同数值，应先澄清，不能直接套用本例去重规则。

示例目标是核对统计口径与结论，不推算市场规模、业务效益或竞赛获奖效果。
