# 人工参考输出：核对记录与修订结论

这是人工期望结果，下面的算术由prove_existing.py独立复算。它不是A诊断、B指导或用户实际执行结果。

| 检查项 | 参考结果 | 处理 |
| --- | --- | --- |
| 原始记录 | 6行 | 保留原始文件 |
| 完全重复 | R03有1条重复行 | 排除重复行并记录原行号 |
| 缺失分母 | R05 | 列为待补信息，不计入本轮有效比率 |
| 单日零分母 | R04，0/0 | 单日比例记为不适用，不伪造为0%或100% |
| 有效唯一记录 | R01、R02、R03、R04 | collected合计60，returned合计42 |
| 合计比率 | 42/60 = 70% | 明确仅针对本例有效记录，不能外推总体 |

修订结论：“按本例完全重复行去重、暂排除缺失分母记录后，有效记录合计比率为70%。另有1条缺失分母记录待核对；本例不支持‘所有记录均有效’或‘回收率100%’。”

最小操作：先打开CSV第4、5行核对R03的字段；记录一条去重依据；再标记R05缺失字段。之后计算合计分子分母，保存分析v2及排除清单，另一成员独立复算。材料版本与原行号必须保留。
