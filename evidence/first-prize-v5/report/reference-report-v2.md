# 人工参考输出：项目方案 v2

这是本轮人工编写的期望结果样例，不是A/B自动生成结果，不记作用户效果或Agent成绩。

## 2.1 需求分析

在本案例提供的五条模拟访谈中，出现了“任务表述不具体，难以判断下一步”的反馈（I01/第1段、I03/第1段），以及“临时占用后需要重新协调安排”的反馈（I02/第1段）。I04/第1段也提供了不同情况：该访谈对象通常能按计划完成，更关注结论核验。这些片段不足以支持“80%的大学生”或“所有人都不会使用计划工具”的总体判断。

因此，本轮产品优先尝试提供材料位置明确的小步骤、剩余任务调整和成果证据检查。I05/第1段仅提供对5分钟启动提示的个人感受，尚不能证明其普遍有效。自动排程能否减少拖延、减少返工，需要后续实际执行与对照测试。

## 2.2 需求与产品动作

| 依据 | 待解决问题 | 最小产品动作 | 验证办法 |
| --- | --- | --- | --- |
| I01、I03/第1段 | 下一步不明确 | 操作卡标出文件、章节、动作、产物、自检与失败下一步 | 首次使用者能打开指定材料并完成一小步，记录所需时间与补问 |
| I02/第1段 | 临时占用导致排期失效 | 扣除受影响空档，预览剩余任务的调整 | 不超容量；已完成记录和证据保留；排不下时报告缺口 |
| I04/第1段 | 结论缺证据或过度断言 | 提交后逐条核对来源与新版本 | 未满足条件进入修改，不因收到建议而直接完成 |
| I05/第1段 | 开始行动困难，效果待验证 | 第一小步上限5分钟，随后记录实际耗时 | 与相同任务下的对照流程比较；当前不声称改善率 |
