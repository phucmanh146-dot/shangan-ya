# 上岸鸭：资料到行动扩展

在原 v7 工作台内增加资料处理流程。保留原每日清单、专注、知识与路线、复盘和浏览器数据。

## 入口与使用

双击原工程中的“启动资料行动.cmd”，在同一浏览器打开 `http://127.0.0.1:8877/index.html`。
进入“知识与路线 → 资料航线工坊”，点击“导入图片 / 视频 / 文档”；顶部也有“资料 → 行动”入口。
原航线中的目标、链接和正文会带入新窗口。

1. 选择或新建成长/竞赛目标，填写交付要求、截止日期、每日可投入时间。
2. 导入 Word/PDF/文字/字幕、图片或视频，或粘贴飞书/网页/公开视频链接。
3. 按需勾选联网搜索，或输入微信关键词，点击“打开微信并读取关键词”；无需先选择群。只查某个群保留在可选折叠区。
4. 依次读取资料、识别画面、提炼核心内容、生成任务草稿。各步骤使用同一目标和来源；失败保留成功步骤。
5. 核对来源，调整任务名称、日期、类别、负责人、重要和紧急，再采用。重复采用不会重复写入任务。
6. 核心内容和来源可保存至备忘；处理记录支持重开窗口和失败重试。

## 针对问题的解析正文

在“你要解决的问题”填写具体问题，再点“按问题解析并写入正文”。程序读取资料后，优先围绕问题选取原文片段，由模型给出直接回答、操作步骤、相关来源及待核实事项。解析完成自动放入“正文 / 笔记 / 字幕”，也可从历史结果点击“将解析放入正文”。

原始正文保留，可点击“返回原始正文”切回。生成的解析不会被再次当成原始证据送入下一轮读取。仅解析问题可以独立完成，无需先生成任务。模型连接失败时保留已读资料并显示错误，不生成假答案。

微信会识别真实聊天主窗口并恢复到前台，排除微信内置网页窗口。只在明确识别的原生搜索框输入关键词，读取可识别的消息搜索结果；不会输入聊天发送框。登录页会提示先进入微信，未开放控件的客户端会保留准确失败原因。匹配消息中的链接会带入链接框，可继续批量读取。

## 远程面板与微信群消息

“远程桌面”入口会先检查并启动原本机8878服务，确认在线后加载面板；失败时显示原因和重连按钮。独立面板的微信关键词搜索复用主服务，搜索不需要AI模型或开启桌面点击许可。群聊、已读消息、尚未展开的匹配会话分别展示，消息可以直接带入资料正文。

支持按关键词识别微信搜索列表中的群聊分区和聊天记录分区；会话的“几条相关记录”计数不会冒充消息正文。只覆盖当前可读取结果。多个微信进程并存时优先识别可读的聊天主窗口；主窗口没有提供控件时提示无法读取，不因另一个登录窗口就把整个微信判为未登录。没有客户端搜索控件时，可复制实际内容到面板带回正文。

桌面画面仍需用户点击“连接桌面”，并单独勾选本次手动点击许可；入口启动服务不自动截屏或点击。关闭面板停止本次画面会话和关键词查找。服务继续只监听127.0.0.1，未开放公网控制。

## 批量链接读取

点击“读取并保存全部链接”可先保存资料，不调用AI模型。一次最多100条链接和12份正文资料，分享文字中的链接会提取并去重，逐条读取；一条失败不会中断其他来源。

“全部资料”显示每条链接已读取、仅有简介或待补充及具体原因。支持只重试某条链接、重试全部未读链接，或用已读取资料继续生成行动。新读入的资料会让旧的诊断和任务草稿失效，防止继续使用过时结论。

PDF、Word、纯文字及字幕的公开直链按文件格式解析。视频标题/简介独立展示，只有取得字幕才作为视频正文使用；平台登录、验证、无字幕或付费权限仍需在原站解决，不能保证所有网站都允许自动读取。

网页读取支持HTTP跳转、公开页面的刷新跳转、微信公众号正文容器、百度搜索结果容器、文章结构化数据和通用正文段落。百度搜索结果会标为结果页，不代表每条搜索结果的全文均已读取。视频字幕支持SRT、VTT、JSON/JSON3和TTML，包括B站内嵌SRT及自动字幕语言；弹幕不作为字幕。单条视频读取55秒超时，不阻塞剩余链接。

## 能力边界

- 模型调用使用电脑已有 CC Switch 配置或原模型设置，连接必须实际验证。无有效凭证或额度时显示真实错误，不显示假成功。
- 飞书沿用原应用身份；文档必须授权该应用读取。遇到登录或验证不会绕过，可导出文件或粘贴正文。
- 视频链接提取公开字幕；无字幕时不把简介冒充视频内容。本地视频最多分析6个采样画面，音轨需提供字幕。本扩展不自动生成讲解视频。
- 微信通过当前登录客户端的可访问控件直接搜索关键词，也可只查指定群；只覆盖当前可读取结果，不代表全部聊天历史。
- 原任务和备忘保存在同一浏览器空间；目标、来源和流程检查点保存在此电脑用户目录中。
- 服务仅绑定本机地址。没有修改原公开域名，也没有把电脑文件、微信或模型密钥开放到公网。

## 安装与恢复

在本目录执行：`python install_workbench.py "原完整网页工程目录"`。
安装前将原首页、启动脚本及已有同名文件复制到工程内 `.growth-backup-时间戳`。
恢复时停止资料行动服务，将该备份中的原文件复制回原位置，再启动原服务。
安装器只替换启动脚本内的服务文件名，不停止已经运行的服务。

## 验证

`python test_pipeline.py` 验证模型上下文传递、来源约束、阶段重试、资料空间隔离、并发更新与输入校验。
测试使用受控模型回复，不能替代真实模型连通性验证。
`node --check growth-workspace.js` 检查脚本语法。
`test_ui.mjs` 使用原工程和已安装的 happy-dom 验证入口、目标预填、任务和备忘写入、去重及弹窗重开。
