# 最初12项功能的闭环标注

原始依据：https://github.com/phucmanh146-dot/shangan-ya/blob/captain/personalized-first-step-provincial-prize-20261026/docs/product-goal-original-features-and-team-dispatch-2026-10-26.md

成果闭环：F01真实材料→F02证据诊断→F03行动卡→真人V2→F04独立复核→F03仅调整剩余项。

过程闭环：卡住/离开→F05/F10存档→F08询问→F09帮助→本人重新尝试→接回F03→F11留证。F06负责第一次进入；F07补当前所需资料；F12保留扩展。

## F01 真实材料接入

- 输入：目标、原件、来源与使用范围
- 输出：可读内容、artifact_id/version、hash、locator；未解析范围
- 交给谁：F02 证据驱动诊断
- 闭环验收条件：原文内容及定位可回查；文件存在不等于读懂
- 失败回到哪：未解析/无权限→UNKNOWN/BLOCKED，补材料后再诊断
- 代码模块：artifact_store.py
- 函数/接口：import_file/read/references
- 原55项编号：9、14、19、24、29、34、39、44、50
- 当前已证实范围：八项目摘录和部分图页已留证；全格式、全部图像与权限未完成验收
- 整体标注：部分接通/真实闭环待验

## F02 证据驱动诊断

- 输入：F01原文、目标标准、当前作品
- 输出：gap、事实/推断/unknown、引用位置、判据和支持性状态
- 交给谁：F03 行动卡与依赖排程
- 闭环验收条件：引用存在且确实支持判断，经内容抽查才放行
- 失败回到哪：错误引文/证据不支持→退回诊断，不消费为正式计划
- 代码模块：team_ai.py
- 函数/接口：documents/researcher/call_json
- 原55项编号：1、5、51
- 当前已证实范围：实际模型调用与失败已有留证；未获得八项目完整语义质量通过
- 整体标注：部分接通/真实闭环待验

## F03 行动卡与依赖排程

- 输入：已放行gap、当前能力证据、工具/时间/依赖
- 输出：具体位置、动作、理由、产物、自检、失败下一步与估时
- 交给谁：真人执行→F04；卡住→F05/F09
- 闭环验收条件：第三人能照做；未知先试做，已验证跳过，容量/依赖未齐不排成可执行
- 失败回到哪：卡片空泛/证据未放行→BLOCKED；仅重排未通过项，保护执行中及待复核成果
- 代码模块：action_planner.py
- 函数/接口：generate；team_handoff.planner；team_revision.plan_remaining
- 原55项编号：2、6、7、8、51、52
- 当前已证实范围：规则规划与新能力分流工程门已测；真实模型候选、容量排程与真人执行仍分别待验
- 整体标注：部分接通/真实闭环待验

## F04 版本保护与成果复核

- 输入：真实V1、本人V2、hash/diff、冻结G与执行者
- 输出：pending_review→逐项PASS/FAIL/UNKNOWN及review_id
- 交给谁：FAIL/UNKNOWN→F03剩余项；PASS→下一轮基线
- 闭环验收条件：非执行者按同一G比较；自己点击完成或模型回执不能关单
- 失败回到哪：旧版本拒收；未知不通过；原件及已完成成果保护
- 代码模块：team_orchestrator.py
- 函数/接口：current/commit；team_handoff.review；team_revision.plan_remaining
- 原55项编号：3、7、11—12、17—18、23、27—28、32—33、37—38、42—43、47—48、53
- 当前已证实范围：版本及复核工程保护有测试；尚无八项目真人V2独立复核全部通过
- 整体标注：部分接通/真实闭环待验

## F05 中断恢复

- 输入：项目/版本、当前位置、已试方法、卡点、下一动作
- 输出：存档点、恢复候选、项目和版本确认
- 交给谁：回到F03原动作；需帮助转F09
- 闭环验收条件：返回准确现场；在途网络请求是否续跑另行核验
- 失败回到哪：版本变化先确认；不把保存现场写成自动续跑模型
- 代码模块：team_recovery.py
- 函数/接口：pause/resume/attempt/context_packet；team_sessions.recover/confirm
- 原55项编号：3、8、48、54
- 当前已证实范围：存档与卡点工程路径已有；完整前端重开和实际用户恢复待验
- 整体标注：部分接通/真实闭环待验

## F06 冷启动

- 输入：模糊愿望、真实任务与手头条件
- 输出：目标草案、半填空/试做、本人首个小产物V0
- 交给谁：F01/F02真实材料诊断，或F03能力试做
- 闭环验收条件：5分钟内开始一个具体动作并留下实际V0；计时和真人产物须有证据
- 失败回到哪：没有材料用明确标注模板启动；真实材料诊断仍BLOCKED
- 代码模块：quality_loop.py
- 函数/接口：transition/proposal（现工作台）；personal_guidance.prerequisites（既有核心）
- 原55项编号：2、6、49、52
- 当前已证实范围：首步规则与试做软件门通过；未证明真实用户5分钟有效产物
- 整体标注：部分接通/真实闭环待验

## F07 资料检索与拒答

- 输入：大白话问题、当前缺口与允许来源
- 输出：1—3条带原文位置的资料，或缺证/求助/替代路径
- 交给谁：F02核支持性；F09只解释当前方法
- 闭环验收条件：真实检索读到内容且适用；来源URL/标题不能当验证
- 失败回到哪：查不到或不支持→拒答/求助，不编造课程和定位
- 代码模块：learning_agent.py
- 函数/接口：run_agent；personal_guidance.resources
- 原55项编号：4、5、6、51、52
- 当前已证实范围：代码有工具/资源入口；通用检索质量与所有外部连接器未验，不标已支持全网
- 整体标注：部分接通/真实闭环待验

## F08 状态感知与干预

- 输入：主动反馈或页面超时/重复错误等轻量信号
- 输出：对当前状态的询问与本人选择
- 交给谁：F09适配帮助→F05恢复
- 闭环验收条件：询问而非心理诊断；不用摄像头推定专注状态
- 失败回到哪：信号不可靠就保持未知，不给用户固定标签
- 代码模块：research_companion.py
- 函数/接口：today/checkin；轻量自动感知范围需另核
- 原55项编号：2、49、54
- 当前已证实范围：已有前台截止询问；自动切后台/停留/错误感知未完整实现验收
- 整体标注：部分接通/真实闭环待验

## F09 个性化帮助

- 输入：实际卡点、试做错误、可用材料及时间
- 输出：当前解释/示例/更小动作/排错或求助
- 交给谁：尝试产物反馈F03；继续原任务F05
- 闭环验收条件：帮助随卡点变化；两轮仍失败应升级求助/暂停
- 失败回到哪：不反复同一泛化建议；不把疲惫判断为不想做
- 代码模块：team_rescue.py
- 函数/接口：start/sync；research_companion.guidance；quality_loop.transition
- 原55项编号：2、6、7、52
- 当前已证实范围：方法/材料/环境/范围与两次失败分流工程门已测；真人帮助有效性待验
- 整体标注：部分接通/真实闭环待验

## F10 跨会话记忆

- 输入：项目、材料版本、位置、尝试、卡点与本人选择有效的帮助
- 输出：可恢复的任务上下文；偏好与项目记录分开
- 交给谁：F05恢复确认后，回F02或F03
- 闭环验收条件：重开后位置和版本正确；不把无界聊天当记忆
- 失败回到哪：切项目/版本不串数据；旧信息失效要显式确认
- 代码模块：team_runtime.py
- 函数/接口：remember/snapshot；team_sessions.recover/confirm；工作台Store
- 原55项编号：3、8、48、50、54
- 当前已证实范围：项目隔离/持久化与冲突工程门有测试；用户偏好长期有效性未验证
- 整体标注：部分接通/真实闭环待验

## F11 工具与可观测

- 输入：输入版本、允许工具、实际调用、返回与错误
- 输出：run/trace、失败、耗时、版本和审计链
- 交给谁：F02/F03/F04按结果放行；失败返回当前环节
- 闭环验收条件：可从产物回查原件、gap、动作和复核；各层成功不互相替代
- 失败回到哪：工具失败不伪装成功，不无限循环或静默换模型
- 代码模块：team_ai.py
- 函数/接口：trace/call_json；learning_agent.run_agent；team_recovery.evaluation_export
- 原55项编号：3、4、8、50、54
- 当前已证实范围：真实模型与工程失败留证已有；当前分支全链同一版本的正式发布门未全部通过
- 整体标注：部分接通/真实闭环待验

## F12 个人版扩展

- 输入：更丰富课程、网页/飞书/视频、休息计时、站外提醒等需求
- 输出：按权限逐个验收的扩展能力
- 交给谁：服务F07/F09/F05；不阻塞核心双闭环
- 闭环验收条件：每个连接器和通知渠道分别证明真实可用
- 失败回到哪：未接通明确未接通；前台提醒不能当后台推送
- 代码模块：路线图
- 函数/接口：未统一接通，不能用单个代码文件代表全部
- 原55项编号：54、55（扩展不替代效果试用）
- 当前已证实范围：保留原路线图；不宣称已实现全部课程库、视频/飞书和站外推送
- 整体标注：规划保留/未统一验收
