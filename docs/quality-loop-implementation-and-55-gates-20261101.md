# 原宗旨对应的质量进阶闭环：本轮实现

入口：http://127.0.0.1:9010/quality 。主页已将它设为主要进阶入口，沿用八项目ID、同一工作台SQLite、上传与下载接口；旧科研选题页不再充当产品主流程。

本轮核心是“现有作品→目标质量→能力与资源分流→本人改稿→同标准比较→另一处迁移”，不是代选一个题目或提醒人开工。

## 已接入软件

- 目标可以先说成“想达到好水平”；Agent依据当前作品给出候选差距及可比较的标准，由本人更正与确认后绑定真实V1和本轮G。没有作品可上传本人现状说明，不把它当研究成果。
- 八项目各3个候选缺口有24种不同具体动作。能力自述不作通过依据；缺材料先求助，未知先试做，试做失败只解释当前方法，再做一行；有有效迁移记录才跳过重复入门练习。
- 两次实际试做失败升级求助；接收具体回复及调整依据后才能恢复，不无限重复同一动作。
- V2必须与V1字节不同；非执行者逐条登记V1哪里未达、V2如何改变、依据及PASS/FAIL/UNKNOWN。未知不算通过，下一轮只补剩余项。
- V2内容通过仅进入迁移门，不直接认证能力。另一处产物不能重复V1/V2，且要有本人方法解释与非执行者复核；通过只记录当前项目、技能和判据，不推断整体科研水平。
- 上传产物可供复核者下载；同名/同代号自我复核、伪造上传hash、跨项目引用、旧版本覆盖均保留拒收。姓名不同不能独立证明实际人员不同。
- 计划和教学提示明确标“透明规则规划，不是模型诊断”。未用人工模板冒充真实模型成功。
