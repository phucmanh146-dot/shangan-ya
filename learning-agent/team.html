  1. C 建项目并上传 V1：填写目标/截止/成员；在“从磁盘选择或拖入真实材料”选择本人作品，用途选“诊断输入”，点击“保存并解析实际文件”。
  2. A 做证据诊断：读取原件和目标标准；在“01 · A 的诊断”接收 Diagnosis，点击“校验并保存诊断”。每条 gap 必须有版本、作品位置、原文证据、目标判据和来源位置。
  3. B 生成行动卡：在“队友交付接线”点击“检查 A 的交付能否进入 B”；没有 errors 后点击“调用 B 规划器并预览”。
  4. C 审计划：在“02 · B 的计划预览”检查微动作、负责人、产物、验收、依赖、估时和失败下一步；确认后点击“采用这份计划”。
  5. 真人执行：在“03 · 执行与成果验收”选择任务，点击“开始任务”；卡住时记录已试操作和实际现象，不虚报完成。
  6. 提交 V2：点击“提交成果”，提交真实文件/版本、证据和实际用时；系统进入“待验收”，不直接判通过。
  7. A 独立复核：导出当前目标、材料与待复核成果给 A；接收复核 JSON，核对版本后保存。复核人不能是该任务执行者。
  8. B 局部重排：只对 FAIL / UNKNOWN / remaining 重新生成行动卡；保留已通过成果、实际耗时和历史。
